# 后端与系统设计面试

本目录整理后端面试中的系统设计、核心基础、电商架构，以及 AI 与 Agent 工程题目。

## 学习路线

- [核心后端基础](question-bank/backend-1000-foundations.md)：覆盖 MySQL、Redis、Kafka、Elasticsearch、网络、操作系统、Docker、Kubernetes、Bash、Python、C++ 和 Go，共 200 个主题、1000 道题。
- [电商系统设计 180 题](question-bank/system-design-ecommerce-180.md)：按电商业务链路分类，覆盖平台、商品、库存、营销、搜索、交易、支付与可靠性。
- [通用与非电商系统设计 100 题](question-bank/system-design-general-100.md)：覆盖系统设计基础、通用技术主题及酒店、出行、内容、协作等非电商系统。

- [AI 与 AI Agent 开发高频面试 50 题](question-bank/ai-agent-50-engineering.md)：覆盖 LLM 基础、Prompt、RAG、Agent、工程化、安全与架构，包含答题主线与追问。

练习时可从题目条件入手，梳理主要方案、关键取舍、异常处理和追问；相关推导、示例与代码随题保留。
