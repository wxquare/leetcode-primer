# 后端与系统设计面试

本目录整理后端面试中的系统设计、核心基础、电商架构，以及 AI 与 Agent 工程题目。

## 学习路线

- [核心后端基础](question-bank/core-backend-foundations.md)：覆盖 MySQL、Redis、Kafka、Elasticsearch、网络、操作系统、Docker、Kubernetes、Bash、Python、C++ 和 Go，共 200 个主题、1000 道题。
- [系统设计面试 50 题](question-bank/system-design-interview-50.md)：电商优先，覆盖交易、高并发、分布式一致性、中间件、安全、可观测性和架构演进。
- [系统设计题库](question-bank/system-design-questionbank.md)：整合原附录 D 的规范题库、训练路线和模拟面试入口。

- [AI 与 AI Agent 开发高频面试 50 题](question-bank/2026-09-26-ai-agent-development-interview-50.md)：覆盖 LLM 基础、Prompt、RAG、Agent、工程化、安全与架构，包含答题主线与追问。

每道题采用三段式：问题、答案、追问。建议先独立回答问题，再阅读答案，最后用追问检查是否真正理解。
