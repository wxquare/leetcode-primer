# 学习路线入口

[仓库首页](../../README.md) / [复习方法](../review-method.md)

本路线把仓库中的题解、模板和复习规则组织成四个阶段。学习记录中的复习状态必须使用 `new`、`review`、`mastered`、`mistake`，并按 [1 -> 3 -> 7 -> 14 天节奏](../review-method.md) 复盘。

## 如何选择起点

| 你现在的状态 | 从哪里开始 | 目标 |
| --- | --- | --- |
| 刚开始刷题，数组、字符串、链表、树还不稳定 | [01 基础阶段](01-foundations.md) | 补齐基础数据结构、递归和二分等必备手感。 |
| 已能独立写基础题，但看到题目还不容易归类 | [02 核心模式](02-core-patterns.md) | 建立高频模式识别能力，稳定解决中等题。 |
| 已掌握常见模式，需要攻克图论、复杂 DP、区间结构或字符串算法 | [03 高级专题](03-advanced-topics.md) | 把模板、复杂题和边界条件整理成可复用能力。 |
| 面试在两周内，重点是限时表现和错题修复 | [04 面试冲刺](04-interview-sprint.md) | 用限时练习、错题复盘、模板召回和重做 `mistake` 项提升稳定性。 |

## 建议顺序

1. 先读 [复习方法](../review-method.md)，确认每道题的状态字段和复习节奏。
2. 从当前水平对应阶段开始，不必重刷已经 `mastered` 的基础题。
3. 每完成一题，把解法要点、失败原因和下次复习日期写入题目笔记。
4. 每周回看 `mistake` 和迟迟无法进入 `mastered` 的题，判断是知识点缺口、模板不熟，还是审题习惯问题。

## 阶段出口

| 阶段 | 可以进入下一阶段的信号 |
| --- | --- |
| [01 基础阶段](01-foundations.md) | 能在不看题解的情况下写出基础数组、链表、树遍历、二分和递归题。 |
| [02 核心模式](02-core-patterns.md) | 看到题目能说出候选模式，并能解释为什么不用另一个相近模式。 |
| [03 高级专题](03-advanced-topics.md) | 能从模板出发完成建模、边界处理和复杂度说明。 |
| [04 面试冲刺](04-interview-sprint.md) | 限时题稳定完成，`mistake` 项被重做并重新进入复习节奏。 |
