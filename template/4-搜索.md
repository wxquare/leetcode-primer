# 搜索专题复习手册

本专题解决两类问题：在有序空间中快速定位答案，以及在离散状态空间中系统探索可能性。题单入口见 [`leetcode/README.md`](../leetcode/README.md#4-搜索)；本文件是搜索专题的详细学习和复习入口。

## 学习地图

| 模块 | 关键问题 | 首选方法 |
| --- | --- | --- |
| 二分查找 | 搜索空间是否有序？答案是否具有单调性？ | 闭区间二分、边界二分、答案二分 |
| BFS | 每一步代价相同，是否要求最少步数？ | 队列按层扩展、访问即入队 |
| 多源/双向 BFS | 有多个起点，或起点和终点都明确吗？ | 虚拟源点、双向扩展 |
| DFS 与回溯 | 是否要枚举路径、组合、排列或满足约束的方案？ | 递归、选择/撤销、剪枝 |
| 逆向与启发式搜索 | 正向状态太多，是否存在更强的终止条件或估价函数？ | 反向标记、A*、状态压缩 |

### 分类边界

- 二分、回溯和网格搜索归入本专题；它们即使出现在数组、字符串或矩阵题中，也按主要搜索模型复习。
- 图的连通性、拓扑排序、Dijkstra、并查集等以图结构为主的内容归入 [`6-图论.md`](6-图论.md)。本文件只保留搜索方法与图论交叉处的 BFS/0-1 BFS 入口。
- 只要求组合数、最值或可达性而不要求具体搜索过程时，优先考虑动态规划，参见 [`5-动态规划.md`](5-动态规划.md)。

## 1. 二分查找：先定义区间和不变量

### 1.1 标准二分

适用条件：数组有序，或谓词 `check(x)` 在搜索区间上具有单调性。开始前先明确区间是闭区间 `[l, r]` 还是半开区间 `[l, r)`，全程不要混用。

```cpp
int l = 0, r = n - 1;
while (l <= r) {                 // 闭区间
    int mid = l + (r - l) / 2;
    if (nums[mid] == target) return mid;
    if (nums[mid] < target) l = mid + 1;
    else r = mid - 1;
}
return -1;
```

边界查找只需改变“命中后的收缩方向”：找第一个满足条件的位置，记录答案后令 `r = mid - 1`；找最后一个则令 `l = mid + 1`。

### 1.2 旋转数组、峰值和二维单调性

- 旋转数组：判断 `mid` 落在左侧还是右侧有序段，再决定舍弃哪一半；存在重复值时，无法判断就收缩一个边界。
- 峰值：比较相邻元素，向上坡方向移动，保留至少一个峰值。
- 二维有序矩阵：若可按行首尾整体展开，直接一维化；若仅行列有序，从右上角或左下角逐步排除区域。

## 2. 答案二分：把最优化改成可行性

适用信号：题目要求“最小的最大值”“最大的最小值”“至少/至多”，并且答案越大（或越小）时可行性只发生一次切换。

```cpp
long long l = lowerBound, r = upperBound;
while (l < r) {
    long long mid = l + (r - l) / 2;
    if (check(mid)) r = mid;       // 找第一个可行值
    else l = mid + 1;
}
return l;
```

`check` 应该只回答“当前答案是否可行”，不要在其中偷偷修改二分边界。先写出可行性的单调关系，再决定是找第一个 `true` 还是最后一个 `true`。注意 `mid * mid`、总和和计数可能溢出，使用 `long long`。

## 3. BFS：无权状态图上的最短步数

把每个状态看成图节点，把一次合法操作看成边。所有边代价相同，第一次出队或第一次入队时得到的距离就是最短距离。

### 3.1 单源 BFS

```cpp
queue<State> q;
q.push(start);
visited.insert(start);
int step = 0;
while (!q.empty()) {
    int sz = q.size();
    while (sz--) {
        State cur = q.front();
        q.pop();
        if (cur == target) return step;
        for (State nxt : nextStates(cur)) {
            if (visited.insert(nxt).second) q.push(nxt);
        }
    }
    ++step;
}
return -1;
```

网格题中把四个方向、边界和障碍判断封装起来；状态题中要明确状态是否需要额外维度，例如“位置 + 是否使用过道具”。访问标记应在入队时完成，避免同一状态重复入队。

### 3.2 多源、双向和带权变体

- 多源 BFS：把所有起点同时入队，初始距离均为 0；适合求每个位置到最近源点的距离。
- 双向 BFS：从起点和终点同时扩展，每轮扩展较小的一侧；适合分支数大、起终点明确的最短步数题。
- 0-1 BFS：边权只有 0 或 1，使用 `deque`，权重 0 的节点从队首加入，权重 1 的节点从队尾加入；完整图论模板见 [`6-图论.md`](6-图论.md)。
- 优先队列搜索：边权非负但不全相等时使用 Dijkstra，而不是普通 BFS。

## 4. DFS 与回溯：枚举、约束和剪枝

回溯的核心是“做选择 → 递归 → 撤销选择”。先判断题目是在求组合、排列、子集、路径还是约束满足，再选择 `start`、`used` 或棋盘状态。

```cpp
void dfs(int start) {
    if (满足终止条件) {
        answer.push_back(path);
        return;
    }
    for (int i = start; i < n; ++i) {
        if (本层重复或不满足剪枝条件) continue;
        path.push_back(nums[i]);
        dfs(i + 1);              // 可重复使用时按题意传 i
        path.pop_back();
    }
}
```

选择口诀：

- 组合/子集用 `start` 保证不回头；排列用 `used` 或位掩码允许从任意未使用位置选择。
- 输入有重复值时先排序，再做树层去重：`i > start && nums[i] == nums[i - 1]`。
- 网格回溯先标记当前位置，递归结束后恢复；不要把“访问过”误当成全局永久访问。
- 约束满足题优先维护可 O(1) 判断的列、对角线、剩余容量等状态。

## 5. 逆向搜索与启发式搜索

- 逆向搜索：当目标区域或边界更容易确定时，从终点、边界或特殊状态反向标记，例如 [130. 被围绕的区域](https://leetcode.cn/problems/surrounded-regions)。
- 状态压缩 BFS：把“当前位置 + 已访问集合”等信息编码进状态，例如 [847. 访问所有节点的最短路径](https://leetcode.cn/problems/shortest-path-visiting-all-nodes)。
- A*：在 Dijkstra 的基础上加入不高估真实剩余代价的启发式函数。八数码实现可参考 [`graph_a_star_eight_puzzle.cc`](../其它常见的题目/src/graph_a_star_eight_puzzle.cc)。
- 剪枝优先：先用边界、奇偶性、剩余容量、当前最优答案等条件排除不可能分支，再考虑更复杂的启发式。

## 易错点清单

- 二分的区间定义、循环条件和返回位置没有成套设计。
- 答案二分没有证明 `check` 的单调性，或把“最大可行”误写成“最小可行”。
- BFS 在出队时才标记，导致状态重复入队；或者层数更新时机错误。
- 多源 BFS 没有把所有源点放在同一层，双向 BFS 没有在两侧访问集合相交时停止。
- 回溯修改了共享状态却没有撤销，或把树层去重误写成树枝去重。
- 网格搜索把方向数组、越界、障碍和访问状态散落在多处，导致边界遗漏。
- 状态中漏掉“已使用道具/已访问节点集合”等决定未来选择的信息。
