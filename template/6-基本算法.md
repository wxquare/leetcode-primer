# 基本算法专题复习手册

本专题负责解决数组、字符串和一般序列中的高频操作模型。完整题单仍以 [leetcode/README.md](../leetcode/README.md#基本算法) 为准；本文件负责方法选择、核心模板、易错点和 7 天复习闭环。

## 学习地图

| 模块 | 识别信号 | 核心工具 |
| --- | --- | --- |
| 双指针 | 两个位置协同移动、原地处理或维护边界 | 对撞、同向、快慢、三指针 |
| 滑动窗口 | 连续子串/子数组，窗口状态可增量维护 | 计数表、哈希表、单调队列 |
| 哈希与计数 | 查找已出现元素、频率或前缀状态 | `unordered_map`、`unordered_set` |
| 排序与选择 | 排序后结构变简单，或只关心第 k 个 | 排序、堆、Quickselect |
| 模拟与分组 | 规则按时间、位置或阶段重复执行 | 状态机、分组扫描、事件排序 |
| 贪心 | 局部选择能留下最多后续空间 | 交换论证、区间贪心、反证 |
| 分治 | 子问题独立，答案在合并阶段产生 | 递归、归并、快速选择 |

## 1. 双指针

### 1.1 对撞指针

有序数组从两端向中间移动。每次移动都要说明被排除的区域为什么不可能产生更优答案。

```cpp
int l = 0, r = static_cast<int>(nums.size()) - 1;
while (l < r) {
    long long sum = 1LL * nums[l] + nums[r];
    if (sum == target) return true;
    if (sum < target) ++l;
    else --r;
}
return false;
```

代表题：1、15、16、18、167、2824。

### 1.2 同向、快慢和分区

读指针扫描输入，写指针维护已经确定的结果；三指针分区时要明确未知区的范围。

```cpp
int write = 0;
for (int read = 0; read < n; ++read) {
    if (keep(nums[read])) nums[write++] = nums[read];
}
return write;
```

代表题：26、27、75、88、283、392。

## 2. 滑动窗口

窗口问题先定义状态，再决定何时扩张和收缩。若窗口满足条件时可以继续收缩，通常需要在收缩过程中更新答案。

```cpp
int left = 0;
for (int right = 0; right < n; ++right) {
    add(nums[right]);
    while (!valid()) remove(nums[left++]);
    answer = max(answer, right - left + 1);
}
```

代表题：3、76、209、219、239、438、567、1004、2024、2962。

注意：含负数的最短子数组通常不能直接使用普通窗口，应改用前缀和 + 单调队列，例如 862。

## 3. 哈希、前缀状态与计数

- 判重：集合只保存是否出现过。
- 频率：映射保存出现次数，适合异位词、配对和窗口题。
- 前缀和：把“区间和为 k”转化为寻找历史前缀和 prefix - k。
- 自定义状态：把多个维度编码成字符串、整数或结构体作为键。

```cpp
unordered_map<long long, int> count{{0, 1}};
long long prefix = 0;
for (int x : nums) {
    prefix += x;
    answer += count[prefix - k];
    ++count[prefix];
}
```

代表题：1、49、128、217、347、454、560、974。

## 4. 排序、Top K 与选择

排序前先确认是否需要保留原顺序。只需要第 k 个元素时，优先考虑堆或 Quickselect，避免不必要的完整排序。

```cpp
int kthLargest(vector<int> nums, int k) {
    nth_element(nums.begin(), nums.end() - k, nums.end());
    return nums[nums.size() - k];
}
```

比较器必须满足严格弱序；priority_queue 的比较方向与 sort 容易写反。代表题：215、347、692、973。

## 5. 模拟、分组与事件扫描

模拟题的关键是把状态、事件顺序和边界写清楚。遇到“同一规则作用于连续区间”，先找断点，再统一处理整组。

- 时间事件：按时间排序，同一时刻要明确先处理开始还是结束。
- 字符串解析：用栈保存嵌套上下文，避免手动回退。
- 矩阵模拟：用方向数组和边界变量统一处理转向。
- 分组扫描：维护当前组的起点、终点和组内状态。

代表题：54、59、71、150、289、394、443、498。

## 6. 贪心

贪心题不能只凭直觉。完成代码前至少写出一种证明：交换论证、局部最优不劣于任意最优解，或反证法。

- 区间调度：按结束时间排序，优先选择最早结束的区间。
- 覆盖与跳跃：维护当前能覆盖的最远位置。
- 单调栈贪心：当前元素更优时弹出仍可被替代的栈顶。
- 差值/收益：把局部贡献转成排序后的前缀或后缀选择。

代表题：45、55、122、134、135、406、435、452、763、871。

## 7. 分治与选择算法

分治需要明确子问题边界、递归终止条件和合并答案的方式。归并排序适合统计跨区间贡献，Quickselect 适合寻找顺序统计量。

代表题：50、148、215、229、240、315、327、493。

## 易错点清单

- 双指针移动后没有证明被跳过的元素不可能成为答案。
- 窗口计数减少时漏减，或满足条件后没有继续收缩。
- 前缀和计数没有初始化 count[0] = 1。
- nth_element 的目标位置写错，或误以为两侧已经完全排序。
- 贪心只有样例验证，没有给出交换或不变量证明。
- 模拟中同一时刻事件的处理顺序不明确。
