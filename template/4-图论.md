## 2. 并查集：动态连通性

**触发词**：连通块、合并、加边、冗余边、按质因子连接。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct DSU {
  vector<int> parent, size;
  int components;
  explicit DSU(int n) : parent(n), size(n, 1), components(n) {
    iota(parent.begin(), parent.end(), 0);
  }
  int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
  bool unite(int a, int b) {
    a = find(a); b = find(b);
    if (a == b) return false;
    if (size[a] < size[b]) swap(a, b);
    parent[b] = a; size[a] += size[b]; --components;
    return true;
  }
}; // 均摊 O(alpha(n))
```

**不变量**：同一连通块的根相同。`unite` 返回 `false` 代表加入该边会形成环。

## 3. DFS/BFS：网格、无权最短路、连通块

**触发词**：岛屿、扩散、最少操作、每次一步、可达、从边界反推。

```cpp
vector<int> bfsDistance(const vector<vector<int>>& g, int start) {
  vector<int> dist(g.size(), -1);
  queue<int> q;
  dist[start] = 0; q.push(start);
  while (!q.empty()) {
    int u = q.front(); q.pop();
    for (int v : g[u]) {
      if (dist[v] != -1) continue;
      dist[v] = dist[u] + 1; // 首次入队才写距离
      q.push(v);
    }
  }
  return dist;
} // O(V+E)
```

**常见坑**：先入队后再标记会重复入队；网格题原地标记要确认允许修改；多源 BFS 将所有源点距离置零后同时入队。

## 4. 拓扑排序：DAG 与剥叶

```cpp
vector<int> topoSort(int n, const vector<vector<int>>& edges) {
  vector<vector<int>> g(n); vector<int> indegree(n);
  for (auto& e : edges) g[e[0]].push_back(e[1]), ++indegree[e[1]];
  queue<int> q;
  for (int i = 0; i < n; ++i) if (indegree[i] == 0) q.push(i);
  vector<int> order;
  while (!q.empty()) {
    int u = q.front(); q.pop(); order.push_back(u);
    for (int v : g[u]) if (--indegree[v] == 0) q.push(v);
  }
  return order.size() == n ? order : vector<int>{};
} // O(V+E)
```

**触发词**：先修关系、依赖、排序、有向环。无向树的“剥叶”使用度数，反复删除度数为 `1` 的点。

## 5. 最小生成树：连接所有点的最小成本

**触发词**：无向、连通所有点、总边权最小。Kruskal 适合边集；Prim 适合稠密图或隐式完全图。

```cpp
long long kruskal(int n, vector<array<int, 3>> edges) { // {w,u,v}
  sort(edges.begin(), edges.end());
  DSU dsu(n); long long cost = 0;
  for (auto [w, u, v] : edges) if (dsu.unite(u, v)) cost += w;
  return dsu.components == 1 ? cost : -1;
} // O(E log E)
```

**不变量**：已选边无环；Kruskal 每次选当前最轻且能连接两块的边。

- 1135. 连接所有城市的最低成本：Kruskal 基础。
- 1168. 水资源分配优化：虚拟源点连水井。
- [1584. 连接所有点的最小费用](https://leetcode.cn/problems/min-cost-to-connect-all-points)：Prim / Kruskal；完全图常用 `O(n^2)` Prim。
- [1489. 找到最小生成树里的关键边和伪关键边](https://leetcode.cn/problems/find-critical-and-pseudo-critical-edges-in-minimum-spanning-tree)：强制/禁用边后重跑。

## 6. 最短路：先判断边权

### Dijkstra：仅非负权

```cpp
using Edge = pair<int, int>; // {to, weight}
const long long INF = (1LL << 60);

vector<long long> dijkstra(const vector<vector<Edge>>& g, int start) {
  vector<long long> dist(g.size(), INF);
  priority_queue<pair<long long,int>, vector<pair<long long,int>>, greater<>> pq;
  dist[start] = 0; pq.push({0, start});
  while (!pq.empty()) {
    auto [du, u] = pq.top(); pq.pop();
    if (du != dist[u]) continue; // 堆中的旧状态
    for (auto [v, w] : g[u]) {
      if (du + w < dist[v]) dist[v] = du + w, pq.push({dist[v], v});
    }
  }
  return dist;
} // O((V+E) log V)
```

### Bellman–Ford / Floyd

- Bellman–Ford：做 `n-1` 轮对所有边松弛；第 `n` 轮还能松弛说明从源点可达负环，复杂度 `O(VE)`。
- Floyd：`dist[i][j]=min(dist[i][j],dist[i][k]+dist[k][j])`；初始化 `dist[i][i]=0`，两段均可达才相加，复杂度 `O(V^3)`。

**常见坑**：Dijkstra 不能有负边；堆存 `{dist,node}`，边存 `{to,weight}`；不可达不能参与加法。

- [407. 接雨水 II](https://leetcode.cn/problems/trapping-rain-water-ii)：边界优先队列扩展。
- [743. 网络延迟时间](https://leetcode.cn/problems/network-delay-time)：Dijkstra。
- [1334. 阈值距离内邻居最少的城市](https://leetcode.cn/problems/find-the-city-with-the-smallest-number-of-neighbors-at-a-threshold-distance)：Floyd。

## 7. 二分图、欧拉路径与桥

### 二分图染色

```cpp
bool isBipartite(const vector<vector<int>>& g) {
  vector<int> color(g.size(), -1);
  for (int s = 0; s < (int)g.size(); ++s) {
    if (color[s] != -1) continue;
    queue<int> q; q.push(s); color[s] = 0;
    while (!q.empty()) {
      int u=q.front(); q.pop();
      for (int v:g[u]) {
        if (color[v] == -1) color[v]=color[u]^1, q.push(v);
        else if (color[v] == color[u]) return false;
      }
    }
  }
  return true;
}
```

相邻点颜色必须相反；每个未染色连通块都要启动一次 BFS。

- [785. 判断二分图](https://leetcode.cn/problems/is-graph-bipartite)、886. 可能的二分法：染色。
- [3373. 连接两棵树后最大目标节点数目 II](https://leetcode.cn/problems/maximize-the-number-of-target-nodes-after-connecting-trees-ii)：树的奇偶距离对应颜色。
- LCP 04. 覆盖：二分图最大匹配（匈牙利）。

### 欧拉路径与 Tarjan 桥

- Hierholzer：沿未用边走到底，再回溯入答案；无向图欧拉回路要求奇度点 `0` 个，欧拉路径要求 `0` 或 `2` 个。
- Tarjan：无向边 `(u,v)` 是桥当且仅当 `low[v] > dfn[u]`；有重边时按**边编号**跳过父边。

- [332. 重新安排行程](https://leetcode.cn/problems/reconstruct-itinerary/)：Hierholzer + 小根字典序。
- 753. 破解保险箱：De Bruijn 图欧拉回路。
- [1192. 查找集群内的关键连接](https://leetcode.cn/problems/critical-connections-in-a-network)：Tarjan 桥。

**网络流触发词**：容量、最多通过量、最少切断代价、点/边不相交路径。残量网络必须有正反两条边。

```cpp
struct Dinic {
  struct E { int to, rev, cap; };
  vector<vector<E>> g; vector<int> level, it;
  explicit Dinic(int n) : g(n), level(n), it(n) {}
  void addEdge(int u,int v,int cap) {
    g[u].push_back({v,(int)g[v].size(),cap});
    g[v].push_back({u,(int)g[u].size()-1,0});
  }
  bool bfs(int s,int t) {
    fill(level.begin(),level.end(),-1); queue<int> q; level[s]=0; q.push(s);
    while(!q.empty()) { int u=q.front();q.pop(); for(auto&e:g[u])
      if(e.cap && level[e.to]<0) level[e.to]=level[u]+1,q.push(e.to); }
    return level[t]>=0;
  }
  int dfs(int u,int t,int f) {
    if(u==t) return f;
    for(int& i=it[u];i<(int)g[u].size();++i){ auto& e=g[u][i];
      if(!e.cap || level[e.to]!=level[u]+1) continue;
      int x=dfs(e.to,t,min(f,e.cap));
      if(x){e.cap-=x;g[e.to][e.rev].cap+=x;return x;}
    } return 0;
  }
  int maxFlow(int s,int t) {
    int flow=0,x; while(bfs(s,t)){fill(it.begin(),it.end(),0);while((x=dfs(s,t,INT_MAX)))flow+=x;} return flow;
  }
};
```

## 9. 原始笔记勘误

| 问题 | 正确原则 |
| --- | --- |
| BFS 先写距离再判访问 | 首次访问时才写距离并入队 |
| Dijkstra 解包和松弛方向混乱 | 堆 `{dist,node}`，边 `{to,weight}`，更短才更新 |
| 拓扑写成 `while(q.empty())` | 必须 `while(!q.empty())` |
| DSU 未初始化连通块数 | `components=n`，成功合并才减一 |
| Floyd 未设对角线/直接 `INF+w` | `dist[i][i]=0`，两段可达才相加 |
| 匈牙利和 Dinic 不完整 | 左右部/残量反向边必须明确维护 |
