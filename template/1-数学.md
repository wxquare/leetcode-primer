> 目标不是背完所有题，而是看到条件就能选出模板、说清前置条件，并在 10 分钟内手写正确版本。

## 使用方式：先识别，再调用模板

| 题目中的信号 | 第一反应 | 先检查什么 |
| --- | --- | --- |
| 质数、因子、倍数、公因数 | 试除 / 筛法 / GCD | `0`、`1`、负数与溢出 |
| 答案对 `MOD` 取模、除法、组合数 | 快速幂 + 逆元 | `MOD` 是否为质数，分母是否互素 |
| 二进制、异或、子集、字母集合 | 位运算 / 位掩码 / Trie | 有符号移位与位宽 |
| 流式数据、等概率随机、打乱 | 水塘抽样 / 拒绝采样 / Fisher–Yates | 样本空间是否等概率 |
| 幂很大、指数为字符串 | 二分快速幂 | 乘法溢出与模乘 |
| 排列、方案数、恰好 K 个 | 组合数 / 补集 / 容斥 | 是否有重复，是否能反向计数 |
| 二维点、曼哈顿距离、共线 | 坐标变换 / 斜率规范化 | 重点、符号和分母为零 |

建议每次刷题按下面四步复盘：

1. **触发词**：是什么条件让我想到这个模板？
2. **不变量**：循环中哪一个量始终正确？
3. **边界**：`0/1`、重复、负数、溢出、不可逆分别怎样处理？
4. **迁移**：如果把输入规模、模数或数据流条件换掉，模板还能否直接用？

## 1. 数论：质数、因数与整除

### 速记卡

- 判断 `n` 是否为质数，只需试除到 `d <= n / d`；不要写 `d * d <= n`，以免乘法溢出。
- 求 `[2, n]` 的全部质数，使用埃氏筛；从 `i * i` 开始标记即可。
- 分解质因数时，每次除尽当前因子；循环结束后若 `x > 1`，剩余的 `x` 本身就是最后一个质因子。
- `gcd(a, b) = gcd(b, a mod b)`；`lcm(a, b) = a / gcd(a,b) * b`，**先除后乘**降低溢出风险。
- 阶乘末尾零的数量等于因子 `5` 的总数：`n/5 + n/25 + ...`。

```cpp
#include <bits/stdc++.h>
using namespace std;

bool isPrime(int n) {
  if (n < 2) return false;
  for (int d = 2; d <= n / d; ++d) {
    if (n % d == 0) return false;
  }
  return true;
}

vector<int> sieve(int n) {                 // O(n log log n), O(n)
  vector<bool> is_prime(n + 1, true);
  if (n >= 0) is_prime[0] = false;
  if (n >= 1) is_prime[1] = false;
  vector<int> primes;
  for (int i = 2; i <= n; ++i) {
    if (!is_prime[i]) continue;
    primes.push_back(i);
    if (i <= n / i) {
      for (long long j = 1LL * i * i; j <= n; j += i) is_prime[j] = false;
    }
  }
  return primes;
}

vector<pair<int, int>> factorize(int x) {  // 前置条件：x >= 1，返回 (质因子, 指数)
  vector<pair<int, int>> factors;
  for (int p = 2; p <= x / p; ++p) {
    if (x % p != 0) continue;
    int exponent = 0;
    while (x % p == 0) ++exponent, x /= p;
    factors.push_back({p, exponent});
  }
  if (x > 1) factors.push_back({x, 1});
  return factors;
}

long long gcdll(long long a, long long b) { return b == 0 ? abs(a) : gcdll(b, a % b); }
long long lcmll(long long a, long long b) { return a / gcdll(a, b) * b; } // 结果须能装入 long long
```

### 数组中每个数的质因数分解：两种方法

设数组长度为 `n`，最大元素为 `M`。若只分解少量数，直接对每个数试除即可；若数组很大且 `M` 可接受，预处理 `spf[x]`（`x` 的最小质因子）更快。

| 方法 | 适用场景 | 预处理 | 分解总复杂度 | 空间 |
| --- | --- | --- | --- | --- |
| 逐个试除 | `n` 较小，或 `M` 很大 | 无 | $O(\sum\sqrt{a_i})$，最坏 $O(n\sqrt{M})$ | $O(1)$，不含返回结果 |
| SPF 最小质因子筛 | `n` 很大且 `M` 可接受 | $O(M\log\log M)$ | $O(n\log M)$ | $O(M)$ |

#### 方法一：每个数独立试除

前置条件：数组元素均为正整数。返回 `(质因子, 指数)`；例如 `12` 返回 `{{2, 2}, {3, 1}}`。

```cpp
vector<vector<pair<int, int>>> factorizeArrayByTrial(const vector<int>& nums) {
  vector<vector<pair<int, int>>> ans;
  ans.reserve(nums.size());
  for (int x : nums) {
    if (x < 1) throw invalid_argument("all numbers must be positive");
    ans.push_back(factorize(x)); // 调用上面的单数试除模板
  }
  return ans;
}
```

#### 方法二：SPF（Smallest Prime Factor，最小质因子）

`spf[x]` 保存 `x` 最小的质因子，如 `spf[12] = 2`、`spf[45] = 3`、`spf[17] = 17`。分解时不断令 `x /= spf[x]`，无需再次从 `2` 开始试除。

```cpp
vector<int> buildSpf(int M) { // O(M log log M)，前置条件：M >= 1
  vector<int> spf(M + 1, 0);
  for (int p = 2; p <= M; ++p) {
    if (spf[p] != 0) continue; // 已有更小质因子，p 不是质数
    spf[p] = p;                // p 是质数，最小质因子就是自己
    if (p <= M / p) {
      for (long long multiple = 1LL * p * p; multiple <= M; multiple += p) {
        if (spf[multiple] == 0) spf[multiple] = p;
      }
    }
  }
  return spf;
}

vector<vector<pair<int, int>>> factorizeArrayBySpf(
    const vector<int>& nums, const vector<int>& spf) {
  vector<vector<pair<int, int>>> ans;
  ans.reserve(nums.size());
  for (int value : nums) {
    if (value < 1 || value >= static_cast<int>(spf.size())) {
      throw invalid_argument("number is outside SPF range");
    }

    vector<pair<int, int>> factors;
    for (int x = value; x > 1;) {
      int p = spf[x];
      int exponent = 0;
      while (x % p == 0) ++exponent, x /= p;
      factors.push_back({p, exponent});
    }
    ans.push_back(move(factors));
  }
  return ans;
}

// 用法：vector<int> spf = buildSpf(*max_element(nums.begin(), nums.end()));
//      auto all_factors = factorizeArrayBySpf(nums, spf);
```

### 常见坑

- 素数判定中把 `if (x % 2 == 0)` 写在所有循环里，只能排除偶数，不能排除 `9、15` 等奇合数。
- “公共质因子”可以先求全体数的 GCD，再分解这个 GCD；不需要枚举每个数。
- 题目要求“不同质因子”时，分解后每个质因子只保留一次；要求“质因子总数”时保留指数。

## 2. 模运算与组合数

### 必背结论

设模数为 `M`：

```text
(a + b) mod M = ((a mod M) + (b mod M)) mod M
(a * b) mod M = ((a mod M) * (b mod M)) mod M
a / b mod M = a * inv(b) mod M
```

最后一条的前提不是“总能除”：只有当 `gcd(b, M) = 1` 时，`b` 在模 `M` 下才有逆元。下面两个模板按模数性质分开记忆。

### 模板一：费马小定理求逆元

**适用条件**：`M` 是质数，且 `a % M != 0`。

费马小定理：`a^(M-1) ≡ 1 (mod M)`，两侧乘上 `a^(-1)` 得：

```text
inv(a) = a^(M-2) mod M
```

适合 `1e9+7`、`998244353` 等常见质数模数；单次求逆复杂度为 $O(\log M)$。

```cpp
using int64 = long long;

int64 modPow(int64 base, long long exp, int64 mod) { // exp >= 0, mod > 0
  int64 ans = 1 % mod;
  base %= mod;
  while (exp > 0) {
    if (exp & 1) ans = ans * base % mod; // 若 mod 接近 1e18，改用 __int128 模乘
    base = base * base % mod;
    exp >>= 1;
  }
  return ans;
}

int64 fermatInverse(int64 a, int64 prime_mod) {
  // 前置条件：prime_mod 为质数，且 a % prime_mod != 0
  return modPow(a, prime_mod - 2, prime_mod);
}
```

**不能用的情形**：`M` 不是质数，或 `a` 能被 `M` 整除。比如模 `12` 时，不能写 `inv(5) = 5^(10) mod 12`。

### 模板二：扩展欧几里得求逆元

**适用条件**：`M` 可以是任意正整数，但必须满足 `gcd(a, M) = 1`。

扩展欧几里得求出贝祖等式 `ax + My = gcd(a, M)` 的一组解；当 GCD 为 `1` 时，`ax + My = 1`，因此 `x mod M` 就是 `a` 的逆元。时间复杂度同样为 $O(\log M)$。

```cpp
long long exgcd(long long a, long long b, long long& x, long long& y) {
  if (b == 0) { x = 1; y = 0; return a; }
  long long x1, y1;
  long long g = exgcd(b, a % b, x1, y1);
  x = y1;
  y = x1 - (a / b) * y1;
  return g;
}

optional<long long> modInverse(long long a, long long mod) {
  long long x, y;
  if (exgcd(a, mod, x, y) != 1) return nullopt;
  return (x % mod + mod) % mod;
}
```

**不能用的情形**：`gcd(a, M) != 1` 时逆元不存在。例如模 `12` 下，`6` 没有逆元；但 `5` 有逆元，且 `5 * 5 ≡ 1 (mod 12)`。

`C(n,k) = n! / (k!(n-k)!)`。若 `M` 为质数且 `n < M`，可预处理阶乘和逆阶乘，再用费马小定理求逆阶乘；若 `M` 非质数，不可直接把分母“取逆”，需要质因数分解、CRT 或组合数递推等额外方法。

### 组合数：三个常用模板

先记选择规则：结果不取模且数值不大，用模板一；模数为质数，用模板二；模数可以不是质数、但每一步分母都与模数互素，用模板三。若模数为合数且分母不互素，三个模板都不能直接解决，需要质因数分解 + CRT 等方法。

#### 模板一：小范围组合数（不取模）

**适用条件**：最终结果能装入 `long long`。利用每一步整除，复杂度 $O(k)$，其中 `k = min(k, n-k)`。

```cpp
long long combSmall(long long n, long long k) {
  if (k < 0 || k > n) return 0;
  k = min(k, n - k);
  long long ans = 1;
  for (long long i = 1; i <= k; ++i) ans = ans * (n - k + i) / i;
  return ans;
}
```

#### 模板二：费马小定理求组合数（质数模数）

**适用条件**：`MOD` 为质数，且预处理上界满足 `n < MOD`。预处理阶乘和逆阶乘为 $O(N)$，每次查询 $O(1)$。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long modPow(long long base, long long exp, long long mod) {
  long long ans = 1;
  base %= mod;
  while (exp > 0) {
    if (exp & 1) ans = ans * base % mod;
    base = base * base % mod;
    exp >>= 1;
  }
  return ans;
}

long long fermatInverse(long long a, long long prime_mod) {
  // 前置条件：prime_mod 为质数，且 a % prime_mod != 0
  return modPow(a, prime_mod - 2, prime_mod);
}

struct CombPrimeMod {
  static constexpr long long MOD = 1'000'000'007LL;
  vector<long long> fact, inv_fact;

  explicit CombPrimeMod(int n) : fact(n + 1, 1), inv_fact(n + 1, 1) {
    for (int i = 1; i <= n; ++i) fact[i] = fact[i - 1] * i % MOD;
    inv_fact[n] = fermatInverse(fact[n], MOD); // fact[n] != 0，因为 n < MOD
    for (int i = n; i > 0; --i) inv_fact[i - 1] = inv_fact[i] * i % MOD;
  }

  long long C(int n, int k) const {
    if (k < 0 || k > n) return 0;
    return fact[n] * inv_fact[k] % MOD * inv_fact[n - k] % MOD;
  }
};

// 用法：CombPrimeMod comb(1'000'000); comb.C(10, 3) 的结果为 120。
```

#### 模板三：扩展欧几里得求组合数（分母与模数互素）

**适用条件**：每一步的分母 `i` 都满足 `gcd(i, MOD) = 1`。适合单次、小 `k` 查询，复杂度为 $O(k\log MOD)$；`modInverse(i, MOD)` 返回空表示逆元不存在。

```cpp
#include <bits/stdc++.h>
using namespace std;

long long exgcd(long long a, long long b, long long& x, long long& y) {
  if (b == 0) {
    x = 1;
    y = 0;
    return a;
  }
  long long x1, y1;
  long long g = exgcd(b, a % b, x1, y1);
  x = y1;
  y = x1 - (a / b) * y1;
  return g;
}

optional<long long> modInverseByExgcd(long long a, long long mod) {
  long long x, y;
  if (exgcd(a, mod, x, y) != 1) return nullopt;
  return (x % mod + mod) % mod;
}

long long mulMod(long long a, long long b, long long mod) {
  return static_cast<__int128>(a) * b % mod; // 防止 long long 乘法溢出
}

optional<long long> combByExgcd(long long n, long long k, long long mod) {
  if (k < 0 || k > n || mod <= 1) return nullopt;
  k = min(k, n - k);
  long long ans = 1 % mod;
  for (long long i = 1; i <= k; ++i) {
    auto inv = modInverseByExgcd(i, mod);
    if (!inv.has_value()) return nullopt; // gcd(i, mod) != 1，不能直接相除
    ans = mulMod(ans, (n - k + i) % mod, mod);
    ans = mulMod(ans, *inv, mod);
  }
  return ans;
}

// 例：combByExgcd(5, 1, 12) 返回 5。
// 注意：combByExgcd(5, 2, 12) 返回 nullopt，因为分母 2 与 12 不互素；
//      这不代表 C(5,2) mod 12 不存在，而是该模板不能直接计算它。
```

## 3. 位运算：把集合和计数压进二进制

### 速记卡

| 操作 | 含义 | 面试口述 |
| --- | --- | --- |
| `x & (x - 1)` | 清除最低位的 `1` | 用于判断 2 的幂、遍历置位位 |
| `x & -x` | 提取最低位的 `1` | `lowbit`，树状数组和异或分组的分界 |
| `(x >> i) & 1` | 读取第 `i` 位 | 使用无符号数避免负数右移语义 |
| `__builtin_popcount(x)` | `int` 中 1 的个数 | `long long` 用 `__builtin_popcountll` |
| `__builtin_ctz(x)` | 尾随零数量 | `x == 0` 时未定义，不可直接调用 |

```cpp
bool isPowerOfTwo(unsigned int x) { return x != 0 && (x & (x - 1)) == 0; }

int popcountManual(unsigned int x) { // O(置位位数)
  int cnt = 0;
  while (x) x &= x - 1, ++cnt;
  return cnt;
}

vector<int> singleNumberIII(const vector<int>& nums) {
  int xor_all = 0;
  for (int x : nums) xor_all ^= x;
  int lowbit = xor_all & -xor_all;
  int a = 0, b = 0;
  for (int x : nums) (x & lowbit ? a : b) ^= x;
  return {a, b};
}
```

当题目出现“每个字符串只含小写字母且两两不能共享字符”，可以把字符集合压成 `26` 位掩码；当题目出现“两个数的最大异或”，考虑从高位到低位贪心或二进制 Trie。

### 易错点

- `1 << 31` 对有符号 `int` 有风险；需要第 31 位时用 `1U << 31` 或 `1LL << i`。
- 异或只适用于成对抵消或位独立计数；“其他数出现 3 次”不能直接异或，需要逐位计数取模。
- `lowbit` 分组的前提是 `xor_all != 0`，否则没有可分的最低置位位。

## 4. 随机算法：先证明等概率

### 拒绝采样：Rand7 实现 Rand10

两次 `rand7()` 等概率得到 `0..48` 共 49 个状态。只接受 `0..39`，因为 40 能被 10 整除；每个余数类恰好有 4 个状态。

```cpp
int rand10() { // rand7() 等概率返回 [1, 7]
  while (true) {
    int x = (rand7() - 1) * 7 + (rand7() - 1); // [0, 48]
    if (x < 40) return x % 10 + 1;
  }
}
```

### 水塘抽样：未知长度流中均匀选 k 个

处理第 `i`（从 1 开始）个元素时，以 `k / i` 概率保留它：随机一个 `[0, i-1]` 下标，若小于 `k` 则替换水塘位置。归纳可得每个已见元素都以 `k / i` 概率在水塘中。面试手写可将随机数简化为 `rand() % (i + 1)`。

```cpp
template <class T>
vector<T> reservoirSample(const vector<T>& stream, int k) {
  // 前置条件：0 <= k <= stream.size()
  vector<T> reservoir(stream.begin(), stream.begin() + k);
  for (int i = k; i < static_cast<int>(stream.size()); ++i) {
    int j = rand() % (i + 1); // 在 [0, i] 中随机选一个位置
    if (j < k) reservoir[j] = stream[i];
  }
  return reservoir;
}
```

> `rand() % (i + 1)` 是面试中的简写；严格追求均匀分布时，使用 `uniform_int_distribution<int>(0, i)(rng)`，避免取模偏差。

### Fisher–Yates 洗牌

第 `i` 次在 `[i, n-1]` 中随机选一个元素与 `a[i]` 交换；这样每一种排列恰好对应一条随机选择路径，概率均为 `1/n!`。

```cpp
template <class T>
void shuffleArray(vector<T>& a) {
  mt19937 rng(random_device{}());
  for (int i = 0; i < static_cast<int>(a.size()); ++i) {
    uniform_int_distribution<int> pick(i, static_cast<int>(a.size()) - 1);
    swap(a[i], a[pick(rng)]);
  }
}
```

## 5. 快速幂：把指数按二进制拆开

`a^n` 中，`n` 的每一位都决定是否把当前的 `a^(2^i)` 乘进答案，因此时间从 `O(n)` 降为 `O(log n)`。指数可能为负时，先转为 `long long` 再取倒数，避免 `INT_MIN` 取反溢出。

```cpp
double myPow(double x, int n) {
  long long exp = n;
  if (exp < 0) x = 1.0 / x, exp = -exp;
  double ans = 1.0;
  while (exp) {
    if (exp & 1) ans *= x;
    x *= x;
    exp >>= 1;
  }
  return ans;
}
```

## 6. 排列、组合与容斥

### 三个切入问题

1. **是否只关心下一种字典序排列？** 用“找下降前的 pivot → 右侧找刚好更大者 → 反转后缀”。
2. **是否在数满足条件的排列/数组？** 先固定必须满足的元素，再数剩余位置的组合或排列。
3. **正向条件太多不好数？** 尝试补集或容斥：`至少一个坏事件 = 总数 - 一个都不坏`，多个坏事件按交集加减。

```cpp
void nextPermutation(vector<int>& a) { // O(n), O(1)
  int i = static_cast<int>(a.size()) - 2;
  while (i >= 0 && a[i] >= a[i + 1]) --i;
  if (i >= 0) {
    int j = static_cast<int>(a.size()) - 1;
    while (a[j] <= a[i]) --j;
    swap(a[i], a[j]);
  }
  reverse(a.begin() + i + 1, a.end());
}
```

## 7. 几何：距离变换与斜率哈希

### 曼哈顿距离变切比雪夫距离

令 `u = x + y`，`v = x - y`，则二维曼哈顿距离满足：

```text
|x1 - x2| + |y1 - y2| = max(|u1 - u2|, |v1 - v2|)
```

因此需要最大曼哈顿距离时，只需维护 `u、v` 的最大最小值；删除一个点后的极值题，则维护每个方向的最大值、次大值及其来源。

### 共线：斜率必须规范化

对固定起点，其他点的方向用 `(dy/g, dx/g)` 表示，其中 `g = gcd(abs(dy), abs(dx))`；统一分母为正。垂直线规范为 `(1,0)`，水平线为 `(0,1)`，重合点单独计数。

题单：

- [3102. 最小化曼哈顿距离](https://leetcode.cn/problems/minimize-manhattan-distances)：`x+y`、`x-y` 极值。
- [149. 直线上最多的点数](https://leetcode.cn/problems/max-points-on-a-line)：斜率哈希 + 规范化。

## 原始笔记模板勘误

| 原问题 | 为什么错 | 正确原则 |
| --- | --- | --- |
| `isPrime` 循环中固定检查 `x % 2` | 对任意奇合数都不会返回 `false` | 检查当前试除数 `d`，即 `x % d == 0` |
| 分解因数时只 `push_back` 不 `x /= i` | `while` 永不推进，可能死循环；`x/i` 不是质因子 | 每次除尽同一质因子，记录指数 |
| 扩展欧几里得把 `x`、`y` 覆盖顺序写错 | 回代系数不再满足 `ax + by = gcd(a,b)` | 先拿子问题 `x1,y1`，再计算 `x=y1, y=x1-(a/b)y1` |
| `pow_mod` 重定义参数 `e` | C++ 无法编译，且含义混乱 | `exp` 保留为 `long long`，不预先对 `MOD` 取模 |
| 拒绝采样成功后不 `return` | 无限循环，无法返回结果 | 仅在 `x < 40` 时 `return x % 10 + 1` |
| 洗牌使用 `rand() % i` | `i=0` 时除零，且交换范围错误 | 第 `i` 轮从 `[i,n-1]` 均匀选择；使用 `<random>` |
| 水塘抽样使用 `rand() % i` | 第 `i` 个位置的随机范围漏掉一个状态 | 下标从零时处理 `i` 时应从 `[0,i]` 选 |
