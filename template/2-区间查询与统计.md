# 区间查询与统计：思路、选型与 C++ 模板

区间题先问“要维护什么”，再问“查询与修改如何交替”。只要把这两个问题分开，前缀和、树状数组、线段树、莫队就不再是零散模板。

## 0. 先选算法：一张表与一棵决策树

| 技术 | 单次查询 | 是否支持更新 | 最适合的问题 |
| --- | --- | --- | --- |
| 前缀和 | $O(1)$ | 否 | 静态区间和、可相减的静态聚合 |
| 差分 | 最后还原 $O(n)$ | 批量区间更新 | 多次修改后统一取结果 |
| 树状数组（BIT） | $O(\log n)$ | 单点更新 | 区间和、频次、逆序对 |
| 线段树 | $O(\log n)$ | 单点或区间更新 | max/min/sum、复杂区间更新 |
| 莫队 | 常见为 $O((n+q)\sqrt n)$ | 仅离线 | 无法快速合并的频次统计 |
| 前缀异或/随机哈希 | $O(1)$ | 通常静态 | 异或状态、频次奇偶的概率校验 |

```text
是否存在“查询和修改交替”？
├─ 否：静态数组
│  ├─ 答案能由两段前缀相减吗？──是→ 前缀和/前缀异或
│  └─ 否：查询能离线重排吗？
│     ├─ 是→ 按右端点扫描 + BIT，或莫队
│     └─ 否→ 分块、可持久化线段树或按题意设计状态
└─ 是：动态数组
   ├─ 单点修改 + 可加/可减聚合→ BIT
   └─ 区间修改或复杂聚合→ Lazy 线段树
```

## 1. 统一约定与常见边界

- 数组下标使用 **0-based**，所有题面区间都写作闭区间 `[l, r]`。
- 前缀和多开一位：`pref[0] = 0`，所以 `sum(l, r) = pref[r + 1] - pref[l]`。
- BIT 内部使用 **1-based**；把外部下标 `i` 映射为 `i + 1`。
- 差分修改 `[l, r] += delta` 时，数组长度必须至少为 `n + 1`，才能安全写入 `diff[r + 1]`。
- 线段树的懒标记不是“延迟建树”，而是“该节点代表的整段尚未下推给子节点的操作”。

## 2. 前缀和与差分

### 识别信号

数组不变但有很多区间和查询，或所有区间更新发生在最终读取结果之前。二维网格中的子矩形和同样属于这一类。

### 推导：从逐段累加到前缀相减

直接计算每个 `[l, r]` 的和要遍历 $r-l+1$ 个数。定义 `pref[i]` 为前 `i` 个元素之和，则 `[l, r]` 恰好等于“前 `r+1` 个”减去“前 `l` 个”。预处理 $O(n)$，每次查询变为 $O(1)$。

差分反过来保存相邻元素的变化量。给 `[l, r]` 同时加 `x`，只会在 `l` 处让变化量增加 `x`，在 `r+1` 处抵消 `x`；因此每次更新为 $O(1)$，最后做一次前缀和还原。

### 模板

```cpp
struct PrefixSum {
    std::vector<long long> pref;
    explicit PrefixSum(const std::vector<int>& a) : pref(a.size() + 1) {
        for (int i = 0; i < (int)a.size(); ++i) pref[i + 1] = pref[i] + a[i];
    }
    long long query(int l, int r) const { return pref[r + 1] - pref[l]; }
};

std::vector<long long> range_add(int n,
                                 const std::vector<std::tuple<int, int, long long>>& ops) {
    std::vector<long long> diff(n + 1), ans(n);
    for (auto [l, r, delta] : ops) {
        diff[l] += delta;
        if (r + 1 < n) diff[r + 1] -= delta;
    }
    for (int i = 0; i < n; ++i) ans[i] = diff[i] + (i ? ans[i - 1] : 0);
    return ans;
}
```

### 易错点与经典题

- `pref` 是长度 `n+1`，不要写成 `pref[r] - pref[l]`。
- 差分适合“先改后查”；每次改后都要查询时，应换 BIT 或线段树。
- 经典题：[303](https://leetcode.cn/problems/range-sum-query-immutable)、[1109](https://leetcode.cn/problems/corporate-flight-bookings)、[253](https://leetcode.cn/problems/meeting-rooms-ii)、[2132](https://leetcode.cn/problems/stamping-the-grid)。

## 3. 离散化

### 识别信号

数值或坐标可达 $10^9$，但实际出现的不同值只有 $n$ 个；数据结构只关心相对顺序、相等性或出现的位置。

### 推导

BIT 和数组线段树需要连续的下标。将所有会出现的值排序去重后，用其在有序表中的位置代替原值；原来 “`x < y`” 的相对关系保持不变，空间从值域大小降为不同值个数。

### 模板

```cpp
std::vector<int> compress(const std::vector<int>& a) {
    std::vector<int> vals = a;
    std::sort(vals.begin(), vals.end());
    vals.erase(std::unique(vals.begin(), vals.end()), vals.end());
    std::vector<int> rank(a.size());
    for (int i = 0; i < (int)a.size(); ++i)
        rank[i] = int(std::lower_bound(vals.begin(), vals.end(), a[i]) - vals.begin());
    return rank; // 0-based rank；接入 BIT 时再 +1
}
```

### 易错点与经典题

- 若更新会引入新值，必须把所有更新值也加入 `vals`；这通常要求离线读入。
- 离散化只保序，不保原始数值间的距离；求真实几何长度时应保留原坐标数组。
- 经典题：[315](https://leetcode.cn/problems/count-of-smaller-numbers-after-self)、[218](https://leetcode.cn/problems/the-skyline-problem)。仓库代码：[coordinate_compression.cc](coordinate_compression.cc)。

## 4. 树状数组与离线扫描线

### 识别信号

需要单点加减与前缀和/区间和；或者可以把所有查询按右端点排序，从左到右扫描。

### 推导：为什么 `lowbit` 能维护前缀和

`tree[i]` 存储以 `i` 为右端点、长度为 `lowbit(i)` 的一段和。查询时不断删去当前下标最低位的 `1`，这些不重叠的小段正好拼成前缀；更新时不断加上最低位，使所有覆盖该位置的段都得到更新。

区间不同元素数不能直接做前缀相减，因为“不同”不是可减聚合。离线按 `r` 扫描：对每个值只让它最近一次出现的位置为 `1`。当扫描到 `r` 时，`BIT.sum(l, r)` 就是 `[l, r]` 内不同数的个数；旧位置需减一，新位置加一。

### 模板

```cpp
struct Fenwick {
    int n; std::vector<int> bit;
    explicit Fenwick(int n) : n(n), bit(n + 1) {}
    void add(int i, int delta) { for (++i; i <= n; i += i & -i) bit[i] += delta; }
    int sum_prefix(int i) const { int s = 0; for (++i; i > 0; i -= i & -i) s += bit[i]; return s; }
    int sum(int l, int r) const { return l > r ? 0 : sum_prefix(r) - (l ? sum_prefix(l - 1) : 0); }
};

std::vector<int> distinct_offline(const std::vector<int>& a,
                                  std::vector<std::pair<int, int>> queries) {
    int n = (int)a.size(), q = (int)queries.size();
    std::vector<int> order(q), ans(q); std::iota(order.begin(), order.end(), 0);
    std::sort(order.begin(), order.end(), [&](int x, int y) { return queries[x].second < queries[y].second; });
    Fenwick fw(n); std::unordered_map<int, int> last; int cur_r = -1;
    for (int id : order) {
        auto [l, r] = queries[id];
        while (cur_r < r) {
            ++cur_r;
            if (last.count(a[cur_r])) fw.add(last[a[cur_r]], -1);
            fw.add(cur_r, 1); last[a[cur_r]] = cur_r;
        }
        ans[id] = fw.sum(l, r);
    }
    return ans;
}
```

### 易错点与经典题

- BIT 的 `add`、`sum_prefix` 和 `sum(l,r)` 必须统一 0/1-based 约定。
- 离线扫描线不能回答“中途修改数组后再查询”的问题。
- 经典题：[307](https://leetcode.cn/problems/range-sum-query-mutable)、[315](https://leetcode.cn/problems/count-of-smaller-numbers-after-self)、[1505](https://leetcode.cn/problems/minimum-possible-integer-after-at-most-k-adjacent-swaps-on-digits)、[DQUERY](https://www.spoj.com/problems/DQUERY/)。仓库代码：[fenwick_tree.cc](fenwick_tree.cc)。

## 5. 线段树

### 识别信号

区间内要维护 `sum`、`max`、`min` 等可合并信息，或需要区间加、区间赋值、区间乘等操作。相比 BIT，它的优势是可以自定义“左右子树如何合并”。

### 推导

把数组递归分成左右两半。一个节点保存其整段的答案，父节点通过 `merge(left, right)` 得到答案。只会访问 $O(\log n)$ 个完全覆盖的节点。若一次更新覆盖整个节点区间，把操作记在该节点的 `lazy`，等真正需要访问子节点时再下推，避免递归到每个叶子。

### 模板：区间加、区间和

```cpp
struct LazySegTree {
    int n; std::vector<long long> sum, lazy;
    explicit LazySegTree(int n) : n(n), sum(4 * n), lazy(4 * n) {}
    void apply(int p, int l, int r, long long v) { sum[p] += v * (r - l + 1); lazy[p] += v; }
    void push(int p, int l, int r) {
        if (!lazy[p] || l == r) return;
        int m = (l + r) / 2; apply(p * 2, l, m, lazy[p]); apply(p * 2 + 1, m + 1, r, lazy[p]); lazy[p] = 0;
    }
    void add(int p, int l, int r, int ql, int qr, long long v) {
        if (ql <= l && r <= qr) return apply(p, l, r, v);
        push(p, l, r); int m = (l + r) / 2;
        if (ql <= m) add(p * 2, l, m, ql, qr, v);
        if (qr > m) add(p * 2 + 1, m + 1, r, ql, qr, v);
        sum[p] = sum[p * 2] + sum[p * 2 + 1];
    }
    long long query(int p, int l, int r, int ql, int qr) {
        if (ql <= l && r <= qr) return sum[p];
        push(p, l, r); int m = (l + r) / 2; long long ans = 0;
        if (ql <= m) ans += query(p * 2, l, m, ql, qr);
        if (qr > m) ans += query(p * 2 + 1, m + 1, r, ql, qr);
        return ans;
    }
    void add(int l, int r, long long v) { add(1, 0, n - 1, l, r, v); }
    long long query(int l, int r) { return query(1, 0, n - 1, l, r); }
};
```
```cpp
#include <bits/stdc++.h>
using namespace std;

struct SegNode {
    int l, r;
    SegNode *leftChild;
    SegNode *rightChild;
    int x;
    int lazy;

    SegNode(int l, int r) : l(l), r(r), leftChild(nullptr), rightChild(nullptr), x(0), lazy(-1) {}

    // 仅在需要递归深入时安全创建子节点
    SegNode *getLeftChild() {
        if (leftChild == nullptr && l < r) {
            int mid = l + (r - l) / 2;
            leftChild = new SegNode(l, mid);
        }
        return leftChild;
    }

    SegNode *getRightChild() {
        if (rightChild == nullptr && l < r) {
            int mid = l + (r - l) / 2;
            rightChild = new SegNode(mid + 1, r);
        }
        return rightChild;
    }
};

class SegTree {
  private:
    void pushDown(SegNode *node) {
        if (node->lazy == -1 || node->l == node->r)
            return;
        
        // 注意：下传 lazy 时只更新已存在的子节点，不盲目 new 新节点
        // 如果子节点尚未创建，递归到它时会自动继承 lazy 逻辑或直接在创建时覆盖
        if (node->leftChild) {
            node->leftChild->lazy = node->lazy;
            node->leftChild->x = node->lazy;
        }
        if (node->rightChild) {
            node->rightChild->lazy = node->lazy;
            node->rightChild->x = node->lazy;
        }
        node->lazy = -1;
    }

    void pushUp(SegNode *node) {
        int max_val = 0;
        if (node->leftChild) {
            max_val = max(max_val, node->leftChild->x);
        }
        if (node->rightChild) {
            max_val = max(max_val, node->rightChild->x);
        }
        node->x = max_val;
    }

    void update(SegNode *node, int l, int r, int val) {
        if (node->l >= l && node->r <= r) {
            node->x = val;
            node->lazy = val;
            return;
        }
        pushDown(node);
        int mid = node->l + (node->r - node->l) / 2;

        if (l <= mid) {
            // 需要深入左子树，按需创建
            update(node->getLeftChild(), l, r, val);
        }
        if (r > mid) {
            // 需要深入右子树，按需创建
            update(node->getRightChild(), l, r, val);
        }
        pushUp(node);
    }

    int query(SegNode *rt, int l, int r) {
        if (rt == nullptr)
            return 0;

        if (rt->l >= l && rt->r <= r) {
            return rt->x;
        }
        pushDown(rt);

        int mid = rt->l + (rt->r - rt->l) / 2;
        int max_val = 0;
        if (l <= mid && rt->leftChild) {
            max_val = max(max_val, query(rt->leftChild, l, r));
        }
        if (r > mid && rt->rightChild) {
            max_val = max(max_val, query(rt->rightChild, l, r));
        }
        return max_val;
    }

  public:
    SegNode *root;

    SegTree(int l, int r) {
        root = new SegNode(l, r);
    }

    void Update(int left, int right, int val) {
        update(root, left, right, val);
    }

    int Query(int left, int right) {
        return query(root, left, right);
    }
};
```



### 易错点与经典题

- 区间加对 `sum` 的影响是 `delta * 区间长度`；对 `max` 则只加 `delta`。
- 区间赋值和区间加是两种不同 lazy 标记，混用时需要规定先后顺序。
- 动态开点只在值域很大且访问稀疏时使用；普通数组优先 `4*n` 静态树。
- 经典题：[307](https://leetcode.cn/problems/range-sum-query-mutable)、[699](https://leetcode.cn/problems/falling-squares)、[2276](https://leetcode.cn/problems/count-integers-in-intervals)、[2916](https://leetcode.cn/problems/subarrays-distinct-element-sum-of-squares-ii)、[3479](https://leetcode.cn/problems/fruits-into-baskets-iii)。仓库代码：[segment_tree.cc](segment_tree.cc)、[区间问题.cc](区间问题.cc)。

## 6. 莫队算法

### 识别信号

查询全部已知、没有修改，答案可在窗口左右端各移动一个元素时 $O(1)$ 或 $O(\log n)$ 更新，但无法由左右子区间直接合并。例如区间不同数、出现次数恰为 `k` 的数的个数、区间众数的某些变体。

### 推导

若按任意顺序处理查询，窗口会频繁大跳。按左端点所在块排序，块内按右端点排序，让 `[L,R]` 的移动尽可能平滑。块长约为 $\sqrt n$ 时，总移动复杂度通常为 $O((n+q)\sqrt n)$；核心不在排序本身，而在 `add(value)` 与 `remove(value)` 对统计量的维护。

### 模板

```cpp
struct MoQuery { int l, r, id; };
std::vector<int> mo_distinct(const std::vector<int>& a, std::vector<MoQuery> qs) {
    int n = (int)a.size(), block = std::max(1, (int)std::sqrt(n));
    std::sort(qs.begin(), qs.end(), [&](const MoQuery& x, const MoQuery& y) {
        int bx = x.l / block, by = y.l / block;
        if (bx != by) return bx < by;
        return (bx & 1) ? x.r > y.r : x.r < y.r;
    });
    auto rank = compress(a); std::vector<int> cnt(n), ans(qs.size()); int distinct = 0, L = 0, R = -1;
    auto add = [&](int i) { if (cnt[rank[i]]++ == 0) ++distinct; };
    auto remove = [&](int i) { if (--cnt[rank[i]] == 0) --distinct; };
    for (const auto& q : qs) {
        while (L > q.l) add(--L); while (R < q.r) add(++R);
        while (L < q.l) remove(L++); while (R > q.r) remove(R--);
        ans[q.id] = distinct;
    }
    return ans;
}
```

### 易错点与经典题

- `remove` 必须在计数减到 `0` 时更新全局指标；`add` 则在从 `0` 变 `1` 时更新。
- 莫队不能在线回答查询；带修改的莫队需要把时间维度也纳入排序，复杂度更高。
- [DQUERY](https://www.spoj.com/problems/DQUERY/) 可用莫队或离线 BIT 双解；[2003](https://leetcode.cn/problems/smallest-missing-genetic-value-in-each-subtree) 属于树上统计思想参考，**不是**标准数组莫队模板的直接套用题。

## 7. 前缀异或与随机哈希

### 识别信号

子数组异或为零、字符出现次数的奇偶状态，或需要以高概率判断两段多重集合的频次奇偶性。

### 推导

异或满足 `x ^ x = 0`，所以 `px[r+1] ^ px[l]` 是 `[l,r]` 的异或和；两个相同前缀异或值之间的子数组异或和为零。对于字符奇偶性，某一位代表一个字符出现次数的奇偶，翻转对应位即可。

随机哈希把每种值映射到随机 64 位权重，区间权重异或为零意味着“每个值出现偶数次”的**高概率**证据。它不是数学上的充分必要条件：碰撞理论上存在，安全性要求高时改用精确 map/计数结构。

### 模板

```cpp
struct SplitMix64 {
    uint64_t state = 0x9e3779b97f4a7c15ULL;
    uint64_t next() { uint64_t z = (state += 0x9e3779b97f4a7c15ULL); z = (z ^ (z >> 30)) * 0xbf58476d1ce4e5b9ULL; z = (z ^ (z >> 27)) * 0x94d049bb133111ebULL; return z ^ (z >> 31); }
};
bool all_even_with_random_xor(const std::vector<int>& a, int l, int r,
                              std::unordered_map<int, uint64_t>& weight, SplitMix64& rng) {
    uint64_t x = 0;
    for (int i = l; i <= r; ++i) {
        if (!weight.count(a[i])) weight[a[i]] = rng.next();
        x ^= weight[a[i]];
    }
    return x == 0; // 概率性结论
}
```

### 易错点与经典题

- 普通前缀异或是精确算法；随机权重异或才是概率哈希，不要混淆。
- 题目要求“至多一个字符出现奇数次”时，要查询相同掩码和仅翻转一位的掩码。
- 经典题：[2588](https://leetcode.cn/problems/count-the-number-of-beautiful-subarrays)、[1915](https://leetcode.cn/problems/number-of-wonderful-substrings)。

## 8. 面试/竞赛选型清单

| 题目特征 | 首选 | 追问时的回答 |
| --- | --- | --- |
| 静态区间和 | 前缀和 | 若有更新改 BIT/线段树 |
| 多次区间加，最后输出数组 | 差分 | 若每次更新后查询改 Lazy 线段树 |
| 单点修改与区间和 | BIT | 需要 max/min 或区间更新改线段树 |
| 区间不同元素数，查询可离线 | 右端点扫描 + BIT | 也可用莫队；扫描线通常更快 |
| 区间频次的复杂指标 | 莫队 | 先确认 `add/remove` 能否快速维护 |
| 大坐标上的 BIT/线段树 | 离散化 | 若操作在线且未知坐标，考虑动态开点 |
| 频次奇偶或异或状态 | 前缀异或 | 随机哈希结论须说明碰撞概率 |

实践顺序：先写最小正确的暴力解确认统计量，再判断它是否可由前缀相减、可由左右节点合并、可由窗口增删维护；这三个问题分别指向前缀和、线段树与莫队。
