## 1. 栈、队列与单调结构

### 1.1 单调栈

栈内元素保持单调。遇到破坏单调性的元素时，弹出的元素可以确定其最近更大或更小元素。

```cpp
vector<int> nextGreater(const vector<int>& nums) {
    vector<int> answer(nums.size(), -1);
    vector<int> st;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!st.empty() && nums[st.back()] < nums[i]) {
            answer[st.back()] = nums[i];
            st.pop_back();
        }
        st.push_back(i);
    }
    return answer;
}
```

代表题：42、84、85、155、316、739。

### 1.2 单调队列

队首是当前窗口最优值，队尾负责删除不可能成为答案的元素；下标过期时从队首移除。

```cpp
deque<int> dq;
for (int i = 0; i < n; ++i) {
    while (!dq.empty() && dq.front() <= i - k) dq.pop_front();
    while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
    dq.push_back(i);
    if (i >= k - 1) answer.push_back(nums[dq.front()]);
}
```

代表题：239、862、1438、1696。

## 2. 链表

链表题优先使用 Dummy Node 统一头节点和普通节点的处理。反转、合并和分组题要先画出指针变化，再写代码。

```cpp
ListNode dummy(0, head);
ListNode* prev = &dummy;
while (prev->next && prev->next->next) {
    ListNode* first = prev->next;
    ListNode* second = first->next;
    first->next = second->next;
    second->next = first;
    prev->next = second;
    prev = first;
}
return dummy.next;
```

代表题：2、19、21、23、24、25、61、82、92、142、148、206。

## 3. 树、BST 与 Trie

### 3.1 二叉树 DFS

先决定递归函数返回什么。若父节点需要子树信息，使用后序 DFS；若需要携带祖先状态，使用参数向下传递。

```cpp
int depth(TreeNode* node) {
    if (!node) return 0;
    return 1 + max(depth(node->left), depth(node->right));
}
```

### 3.2 BST

BST 的中序遍历有序。验证、查找第 k 小和构造问题，要明确是否依赖这个有序性质。

### 3.3 Trie

Trie 节点保存字符层级的子节点和是否为完整单词。查询完整单词时必须检查 is_end，前缀查询不需要。

代表题：94、98、105、208、211、212、230、236、297、450。

## 4. 并查集

并查集适合处理“不断合并集合并查询是否连通”。路径压缩和按大小合并后，单次操作的均摊复杂度接近常数。

```cpp
class DSU {
    vector<int> parent, size;
public:
    explicit DSU(int n) : parent(n), size(n, 1) {
        iota(parent.begin(), parent.end(), 0);
    }
    int find(int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (size[a] < size[b]) swap(a, b);
        parent[b] = a;
        size[a] += size[b];
        return true;
    }
};
```

代表题：128、200、305、547、684、721、765、947、959。

## 5. 区间查询结构

### 5.1 树状数组

树状数组适合单点更新和前缀聚合。lowbit(i) = i & -i 表示节点覆盖的最低位区间长度。

```cpp
void add(int i, long long delta) {
    for (; i <= n; i += i & -i) bit[i] += delta;
}
long long sum(int i) {
    long long result = 0;
    for (; i > 0; i -= i & -i) result += bit[i];
    return result;
}
```

### 5.2 线段树

线段树适合自定义区间合并、区间更新和懒标记。先确定节点维护的信息和合并律，再决定是否需要懒传播。

### 5.3 ST 表与离线算法

静态区间幂等查询可使用 ST 表；需要重新排列查询顺序、维护窗口状态时，可考虑莫队算法。完整区间查询模板见 [专题-区间查询与统计.md](专题-区间查询与统计.md)。

## 6. 数据结构设计题

- LRU：哈希表定位节点，双向链表维护最近使用顺序。
- LFU：按频次维护链表，并记录当前最小频次。
- RandomizedSet：数组保证随机访问，哈希表记录值到下标的映射。
- Skiplist：多层前向指针实现平均 O(log n) 的查找和更新。

代表题：146、155、295、380、381、432、460、519、528、705、706、1206。

## 易错点清单

- 单调栈中存值而不是下标，导致无法判断元素是否过期或计算距离。
- 链表删除节点后继续使用已经断开的指针，或忘记处理头节点。
- 树递归返回值与调用者需要的信息不一致。
- Trie 的前缀存在误当成完整单词存在。
- 并查集合并前没有先找根节点。
- 树状数组下标从 0 开始却没有统一转换为 1-based。
- 线段树懒标记下推后没有清空父节点标记。
- LRU/LFU 更新顺序错误，导致访问后顺序或最小频次不正确。
