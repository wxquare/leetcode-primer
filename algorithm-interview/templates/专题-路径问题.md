# 路径问题：建模、选型与方案恢复

路径问题不是单一算法类别。先判断状态空间是什么，再判断边权、目标和是否需要恢复方案，最后选择搜索、动态规划、树上算法或最短路。

## 0. 选型决策表

| 问题信号 | 首选模型 | 常用算法 |
| --- | --- | --- |
| 网格中求最少步数 | 单元格为节点、移动为等权边 | BFS / 多源 BFS |
| 网格中求最小代价 | 移动为带权边 | 0-1 BFS / Dijkstra |
| 只向右或向下并求计数、最值 | 有向无环状态转移 | 动态规划 |
| 树上根到叶或任意两点 | 唯一路径、最近公共祖先 | DFS / LCA / 树形 DP |
| 一般图的最短或次短路径 | 带权图 | Dijkstra / Bellman–Ford / 分层状态 |
| 需要输出路径本身 | 状态记录前驱 | 前驱数组 + 逆序恢复 |
| 目录、坐标或指令轨迹 | 栈或坐标状态机 | 模拟 |

## 1. 网格与二维结构

网格题先明确移动方向、每步代价、障碍是否变化以及能否重复访问。等权最短步数使用 BFS；多起点同时扩散使用多源 BFS；方向代价只有 0 和 1 时使用 0-1 BFS；只按固定方向转移时优先考虑动态规划。

## 2. 树上路径

树中任意两点之间的简单路径唯一。根到叶问题传递当前路径状态；任意两点问题通常把节点向父节点的贡献与“经过当前节点”的完整答案分开；多次路径查询使用最近公共祖先或树链剖分。

## 3. 图上路径

无权图使用 BFS，非负权使用 Dijkstra，存在负边时考虑 Bellman–Ford，全源小图使用 Floyd。次短路和带额外条件的路径需要把“阶段、次数或已用资源”并入状态。

## 4. 动态规划路径

当状态转移天然无环时，用 `dp[state]` 表示到达状态的计数或最优值。先写清状态含义、入口、转移顺序和不可达值，再决定是否压缩空间。

## 5. 路径构造与方案恢复

只求最优值不等于能输出方案。搜索和最短路记录前驱节点，动态规划记录最优转移来源；从终点沿前驱回溯，再反转得到正向路径。存在多条最优路径时，需要额外定义字典序或去重规则。

## 6. 字符串与移动轨迹

目录简化、坐标移动和机器人指令通常不需要图算法。使用栈维护层级，或使用坐标和方向状态机逐条执行规则；只有状态可能重复并要求最少操作时，才提升为图搜索。

## 7. 复杂度与易错点

- BFS 必须在入队时标记访问，避免同一状态重复入队。
- Dijkstra 不适用于负权边；0-1 BFS 只适用于边权 0 或 1。
- 树上 DFS 要区分向父节点返回的单支贡献与经过当前节点的完整路径。
- 路径计数要明确是否允许重复节点、结果是否取模。
- 方案恢复必须保证每个前驱都来自合法的最优转移。
